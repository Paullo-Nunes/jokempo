# Jokempô

Um jogo de pedra, papel e tesoura para jogar no navegador. Escolha uma opção e dispute uma rodada contra a máquina; o placar acompanha as vitórias de cada lado.

## Como jogar

1. Abra o jogo no navegador.
2. Escolha pedra, papel ou tesoura pelos botões.
3. Veja o resultado da rodada e o placar atualizado.
4. Use o ícone de menu para consultar as regras.

As regras são:

- Pedra vence tesoura.
- Tesoura vence papel.
- Papel vence pedra.
- Escolhas iguais resultam em empate.

## Como executar

Não é necessário instalar dependências. Baixe ou clone este repositório e abra o arquivo `index.html` em um navegador.

## Tecnologias
